# Instagram 数据集样本

<h2>包含 2180 位 Instagram 编程网红的示例数据集</h2>

![Instagram 数据集标题](https://github.com/bright-cn/Instagram-dataset-samples/blob/main/Instagram-datasets-cn.png)

一个包含 2000 多位 Instagram 顶尖 [GitHub](https://www.instagram.com/explore/tags/github/) 编程网红的 GitHub 数据集示例。该数据集使用 <b>Bright Data 采集器</b> 提取。

<h2>此免费数据集包含的数据点：</h2>

* 粉丝数量
* 个人资料类型
* 账户类型
* 互动评分
* 类别
* 位置
* 外部链接/个人简介链接
* 使用的标签
* 品牌关联
* 个人简介
* 精选动态
* 帖子



这是“所有 Instagram 账户、企业和非企业（公开数据）”数据集的示例子集，该数据集包含 <b>614,000,000 个 Instagram 个人资料</b>。

在此示例中，我们使用 Bright Data 控制面板提供的智能筛选查询，将大型数据集筛选为较小的子集。
<h2>用于筛选此子集的查询：</h2>


*   	$or: [{"post_hashtags":"github"},{"bio_hashtags":"github"}]
*   	followers: {"$gt":100}

其他筛选查询值包括：<b>帖子数量、国家/地区、认证账户、多种标签组合等。</b>

可用的数据集文件格式：<b>JSON、NDJSON、JSON Lines、CSV 或 Parquet。</b>。

数据集交付方式选项：<b>API 下载、Amazon S3、Google Cloud、Microsoft Azure、SFTP</b>。

可在已提取的数据点基础上额外提供数据增强：<b>平均帖子互动率、品牌关联等。</b>
